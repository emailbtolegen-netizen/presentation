# ЖКХ города Атырау — презентация

Веб-презентация отдела ЖКХ и жилищной инспекции г. Атырау: текущее состояние, основные проекты и потребность в бюджетном финансировании.

## Просмотр

Откройте `index.html` в браузере.

- `←` `→` или пробел — листать слайды
- `F` — полный экран
- `M` — список слайдов
